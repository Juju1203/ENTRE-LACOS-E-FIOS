# Entre Laços e Fios

Página de vendas estática da coleção **Roupinhas para Bebês em Tricô**.

## Publicar no GitHub

1. Crie um repositório vazio no GitHub.
2. Envie todo o conteúdo desta pasta para a raiz do repositório.
3. Confirme que `index.html`, `vercel.json` e as imagens estão na raiz.

## Publicar na Vercel

1. Na Vercel, selecione **Add New → Project**.
2. Importe o repositório do GitHub.
3. Em **Framework Preset**, escolha **Other**.
4. Não configure comando de build.
5. Mantenha o diretório de saída vazio e clique em **Deploy**.

O site não precisa de Node.js, dependências ou processo de compilação.
